Subscribe in Apple Calendar

  1. Sign in to the user portal.
  2. Open Calendar and generate your subscription URL (shown once).
  3. On Mac: Calendar → File → New Calendar Subscription… → paste the HTTPS ICS URL.
  4. On iPhone/iPad: Settings → Calendar → Accounts → Add Account → Other → Add Subscribed Calendar → paste the URL.
  5. Keep auto-refresh enabled. Apple decides when to re-fetch; portal “Sync” updates the feed, not Apple’s pull schedule.

Use HTTPS. If you rotate the token, remove the old subscription and add the new URL.
